# CalcPro — Smart Calculator & Unit Converter

A modern, responsive web and mobile calculator application featuring Standard math, Scientific functions, and multi-unit conversions (length, volume, weight, and temperature).

![CalcPro](https://img.shields.io/badge/Platform-Web%20%7C%20Mobile-blueviolet)
![License](https://img.shields.io/badge/License-MIT-brightgreen)

---

## 🚀 Features

### 1. 🧮 Standard Calculator
- Essential arithmetic operations: Addition (`+`), Subtraction (`−`), Multiplication (`×`), and Division (`÷`).
- Percentage calculations (`%`) and positive/negative sign toggle (`±`).
- Real-time expression evaluation and history tracking.
- Full physical keyboard support (Numpad, Enter, Backspace, Esc).

### 2. 🔬 Scientific Calculator
- **Trigonometric Functions**: `sin`, `cos`, `tan` + Inverse functions (`sin⁻¹`, `cos⁻¹`, `tan⁻¹`) via `INV` toggle.
- **Angle Modes**: One-click switching between `RAD` (Radians) and `DEG` (Degrees).
- **Logarithmic Functions**: Base-10 Log (`log`), Natural Log (`ln`).
- **Exponents & Powers**: `x²`, `x³`, `xʸ`, `10ˣ`, and `eˣ`.
- **Additional Functions**: Square root (`√`), Factorial (`x!`), Absolute value (`|x|`), and mathematical constants (`π`, `e`).

### 3. 📐 Unit Converter
Live bidirectional unit converter with one-click swap and instant quick reference cards:
- **Length**: Millimeter (mm), Centimeter (cm), Meter (m), Kilometer (km), Inch (in), Foot (ft), Yard (yd), Mile (mi), Micrometer (μm), Nanometer (nm).
- **Volume**: Milliliter (mL), Liter (L), Cubic centimeter (cm³), Cubic meter (m³), US Gallon, UK Gallon, Quart, Pint, Cup, Fluid Ounce (fl oz), Tablespoon, Teaspoon.
- **Weight**: Milligram (mg), Gram (g), Kilogram (kg), Metric Ton (t), Ounce (oz), Pound (lb), Stone (st).
- **Temperature**: Celsius (°C), Fahrenheit (°F), Kelvin (K).

## 💻 Getting Started

### Run Locally
Simply open `index.html` in any modern web browser, or serve it locally with:

```bash
# Using npx
npx serve .

# Or using Python
python -m http.server 3000
```

Access the app at `http://localhost:3000`.

---

## 📱 Mobile Access
Connect your mobile device to the same local Wi-Fi network and navigate to:
```text
http://<your-local-ip>:3000
```
